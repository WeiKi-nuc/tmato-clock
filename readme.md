# 番茄钟 + 任务看板

一个功能完整的番茄钟与任务看板应用，帮助您提高工作效率和时间管理能力。

## 功能特性

### 番茄钟核心系统
- 标准番茄循环：25分钟专注 + 5分钟短休息，每4个番茄后15分钟长休息
- 自定义时长：可调整专注/短休息/长休息时长，内置多种预设方案
- 任务绑定：每个番茄钟必须关联看板上的一个具体任务
- 中断处理：记录内部中断（走神）和外部中断（被打扰），影响统计
- 自动切换：专注结束自动提示休息，休息结束提示开始下个番茄
- 声音提醒：开始/结束提示音

### 任务看板系统
- 多列看板：默认三列（待办/进行中/完成），支持自定义列
- 任务属性：预估番茄数、实际番茄记录、优先级标记（四象限）、标签系统、截止日期
- 任务详情：点击展开描述、预估番茄数、实际番茄记录
- 快速操作：开始番茄钟、编辑任务

### 数据统计与分析
- 日报视图：今日完成番茄数、任务完成率、中断次数
- 周报视图：趋势图表、最佳工作天数
- 效率曲线：一天内各时段专注度统计
- 预估准确度：预估vs实际番茄对比，训练时间感知能力
- 连续记录：连续工作天数 streak

### 智能辅助功能
- 智能建议：基于历史数据，推荐当前最适合的任务
- 番茄配对：相似难度任务建议连续完成，减少上下文切换
- 每日计划：快速规划今日任务，分配预估番茄数

### 数据与同步
- 本地存储：SQLite 存储任务与番茄记录
- 自动保存：数据变更自动持久化

## 使用指南

### 1. 创建任务
- 在看板视图中点击"+ 新建任务"按钮
- 填写任务标题、描述、预估番茄数、优先级、标签和截止日期

### 2. 开始番茄钟
- 在看板视图中点击任务卡片的"▶ 开始"按钮
- 或在番茄钟视图中点击"选择任务"选择要专注的任务
- 点击"开始专注"按钮启动计时器

### 3. 记录中断
- 专注过程中如有中断，点击"⚠️ 记录中断"按钮
- 选择中断类型（内部/外部）并添加备注

### 4. 查看统计
- 点击侧边栏的"📊 统计"按钮
- 查看今日概览、本周概览、连续记录、预估准确度等数据

### 5. 任务管理
- 任务完成后会自动记录完成时间
- 逾期任务会自动标红提醒

## 核心类说明

### PomodoroTimer（番茄钟引擎）
职责：计时器核心逻辑与状态管理
- 支持开始、暂停、恢复、停止操作
- 自动记录番茄完成情况
- 支持中断记录

### Task（任务实体）
职责：单个任务的完整数据与行为
- 属性：标题、描述、优先级、标签、截止日期、预估/实际番茄数
- 方法：添加番茄记录、计算完成率、移动看板位置

### KanbanBoard（看板管理器）
职责：看板布局与任务流转控制
- 管理多列看板
- 任务筛选和排序
- WIP限制检查

### TaskRepository（任务仓库）
职责：任务数据的持久化与查询
- SQLite数据库存储
- 任务CRUD操作
- 番茄记录查询

### StatisticsEngine（统计引擎）
职责：数据分析与报表生成
- 日报/周报生成
- 效率曲线分析
- 预估准确度计算
- 连续记录统计

### SmartScheduler（智能调度器）
职责：任务推荐与计划优化
- 基于优先级和截止日期的任务推荐
- 每日计划建议
- 任务超负荷检测

## 配置说明

### 默认番茄钟设置（分钟）
- 专注时长：25分钟
- 短休息：5分钟
- 长休息：15分钟
- 长休息间隔：4个番茄

### 预设方案
- 标准番茄：25/5/15
- 短番茄：15/3/10
- 长专注：50/10/30

### 优先级配置
- 紧急且重要
- 紧急不重要
- 重要不紧急
- 不紧急不重要

## 数据存储

应用数据存储在项目目录下的 `data/` 文件夹中：
- `pomodoro.db` - SQLite数据库文件
- `config.json` - 用户配置文件
